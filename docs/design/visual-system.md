# 共用視覺、狀態與無障礙規範

使用者選定的視覺方向是 [第二輪第 2 張](Vigiloom-UI-Concept-2-Revision-2.png)，SHA-256 `aecda1601afb22f0b7c388fe786a9e9316de93f866ff6278042ed7f64ba30753`。它是視覺及資訊層級參考，不是資料或功能的假畫面；設備與服務分區、網路測速選單、群組與權限均以產品需求為準。

## 選型與約束

- **元件**：MudBlazor 9.12.0（MIT），.NET 10 相容；由 Web.Client 統一引用並在 Server／WebAssembly 註冊服務。Vigiloom 自有封裝控制狀態文字、主題與無障礙語意，不讓各功能各裝一套元件庫。
- **圖表**：Vizor.ECharts 0.9.7／Apache ECharts 6（Apache-2.0），統一由 Web.Client 使用。圖表封裝接收已授權、已整理的資料；不要自行由圖表取得任意來源或把客戶資料送往第三方。監控序列保留缺值與實際時間，不將未知補成零。
- 使用 [NuGet 集中版本](../../Directory.Packages.props)。選型參考 [MudBlazor 套件與授權](https://www.nuget.org/packages/MudBlazor/9.12.0)、[Vizor.ECharts 套件與授權](https://www.nuget.org/packages/Vizor.ECharts/0.9.7)；實際 SSR／Server／WebAssembly 與圖表載入必須在本需求測試，不以套件宣稱支援當驗證結果。
- 顏色與空間來自共享樣式 token：主文字深藍、背景淡藍灰、卡片白色、主要操作亮藍；以 4／8 px 節奏安排間距，表單控制目標至少 44 px 高。字體採本機系統無襯線字體，不依賴第三方字型 CDN。

## 資料狀態

| 情況 | 呈現原則 |
|---|---|
| 正常 | 綠色搭配「正常」及文字或圖示 |
| 警告／降級 | 琥珀色搭配具體文字，不等同完全中斷 |
| 異常／中斷 | 紅色搭配具體問題及可操作的下一步 |
| 未知／未量測 | 中性色與「未知／尚無資料」，不可顯示為正常或 0 |
| 過期 | 標示資料過期與最後成功時間，不混同已離線 |
| Agent 失聯 | 明示 Agent 失聯，與設備 Ping、服務健康分開 |
| 不支援／權限不足 | 顯示能力缺口或權限不足，不把設備整體判為離線 |
| 載入中／空白／失敗 | 有清楚文字，失敗提供安全重試；先前資料若保留要標示過期 |

圖表提供單位、時間範圍、可讀的文字或表格替代；缺值斷線，不能僅靠顏色或 hover 傳達狀態。狀態意義由各領域定義，視覺共用不將不同來源的狀態合併。

## 互動與版面

- 每個輸入有可見標籤、錯誤訊息與關聯；可用鍵盤操作，焦點清楚可見，操作結果有適當的即時文字回饋。
- 正文、按鈕、表格與圖表資訊需符合 WCAG 2.2 AA 對比；狀態及重要圖示有文字、形狀或其他非色彩區別。
- 窄螢幕保留主要導覽與必要操作；寬表格可水平捲動並標示，不能讓欄位或鍵盤焦點消失。不要依賴滑鼠 hover 才能看到關鍵資訊。
- 長列表有界分頁；耗時工作顯示進行中，重試、連線失敗和權限撤銷不可顯示為成功。選取資料跨狀態變更時須重新授權，不能保留已撤銷資訊。
- 靜態 SSR／互動 Server／WebAssembly 共用一致字體、狀態與授權語意；JS 僅在互動後使用。選用 SSR 預載時避免把匿名不應取得的資料寫入 HTML。
