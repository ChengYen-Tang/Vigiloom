# REQ-08 群組設計

沿用使用者選定的 [第二輪第 2 張](Vigiloom-UI-Concept-2-Revision-2.png)，使用淺色背景、白色內容卡與藍色主要操作；保留設備和應用服務各自的身分、欄位與狀態。

- 群組採平面結構；名稱去除前後空白後必填且在資料庫定序規則下唯一，說明選填。管理員建立、編輯或刪除；Read only 可以瀏覽搜尋，不顯示管理操作。
- 群組詳情分區呈現設備與應用服務。設備清單提供搜尋、分頁與詳情連結，管理員可批次加入或移除；未分組設備提供獨立查詢。沒有真實資料或功能時，不使用示範資料或偽造狀態。
- 刪除前顯示受影響的設備歸屬數量並要求確認；只刪除群組及成員關係，不刪除設備、應用服務與歷史，也不變更公開或監測設定。
- 應用服務成員及匿名群組投影須分別待 REQ-22、REQ-12 的真實身分與公開查詢可用後整合驗證。這些驗收未完成前不得將 REQ-08 整體標記 Done。
