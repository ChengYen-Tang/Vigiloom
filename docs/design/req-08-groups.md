# REQ-08 群組設計

沿用使用者選定的 [第二輪第 2 張](Vigiloom-UI-Concept-2-Revision-2.png)，使用淺色背景、白色內容卡與藍色主要操作；保留設備和應用服務各自的身分、欄位與狀態。

- 群組採平面結構；名稱去除前後空白後必填且在資料庫定序規則下唯一，說明選填。管理員建立、編輯或刪除；Read only 可以瀏覽搜尋，不顯示管理操作。
- 群組詳情分區呈現設備與應用服務。設備清單提供搜尋、分頁與詳情連結，管理員可批次加入或移除；未分組設備提供獨立查詢。沒有真實資料或功能時，不使用示範資料或偽造狀態。
- 刪除前顯示受影響的設備歸屬數量並要求確認；只刪除群組及成員關係，不刪除設備、應用服務與歷史，也不變更公開或監測設定。
- 應用服務成員使用 REQ-22 的正式服務身分；匿名群組投影及服務詳情導覽分別待 REQ-12、REQ-25 整合驗證。這些驗收未完成前不得將 REQ-08 整體標記 Done。

## 介面檢查

使用隔離的臨時資料庫與測試帳號，在產品頁面檢查群組建立、設備與服務分區及加入成員；資料庫已依測試擁有權規範清除。畫面沿用既定藍白、深色文字與簡潔卡片風格；原總覽參考圖用於確認共用視覺方向，不當成群組頁的逐像素設計稿。

1. [群組清單空狀態](req-08-groups-list.jpg)：可辨識新增與未分組入口。
2. [新增群組](req-08-groups-create.jpg)：名稱、選填說明與儲存操作清楚。
3. [群組詳情空狀態](req-08-groups-detail.jpg)：設備及服務分區清楚，空清單不顯示頁碼；刪除操作以紅色區分並要求確認。
4. [桌面成員畫面](req-08-groups-desktop.jpg)：兩種成員分區顯示，篩選與對應操作分開；桌面無需橫向捲動時不顯示捲動提示。
5. [390px 成員畫面](req-08-groups-mobile.jpg)：篩選欄位換行，表格顯示捲動提示；實際向右捲動後可看到[設備](req-08-groups-mobile-scroll.jpg)及[服務](req-08-groups-mobile-service-scroll.jpg)的末端欄位。

瀏覽器檢查涵蓋桌面與窄螢幕畫面以及管理員新增群組、加入設備／服務；角色授權、移出與並行衝突由 SQL／HTTP 測試補充。完整鍵盤、讀屏與公開群組驗證仍未完成；服務詳情連結待 REQ-25。
