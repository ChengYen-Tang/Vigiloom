# Agent inbox retention settings

The platform Agent settings page uses the existing blue-and-white card system. The inbox section shows cleanup readiness, the configured replay and retention periods, and committed receipt deletion totals. Before cutover it explicitly asks the administrator to stop and drain older receivers and keep them from rejoining; this is a human assertion, not automatic node detection. Once enabled, changes go through a preview. The preview count is the number of receipts present, not a deletion estimate; extending a window cannot restore data or reopen a cleaned range.

The selected Vigiloom overview is a style reference, not a matching design of this settings screen. In an isolated test database, the actual desktop page was opened in the in-app browser: cutover, preview and cancel were exercised, and cancel restored the previous settings. The initial text contrast was adjusted; the [updated preview capture](req-39/inbox-preview-desktop.png) shows the resulting desktop state. This is not an exact same-screen fidelity comparison.

At a verified 390 × 844 viewport, the [preview](req-39/inbox-preview-mobile.png) remained readable without page-level horizontal overflow. Tab moved from replay to retention, confirm and cancel; Enter on cancel restored the prior values. This is a focused keyboard check, not a complete keyboard or screen-reader accessibility review.
