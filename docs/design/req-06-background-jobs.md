# REQ-06 背景工作介面

依使用者選定的 [第二輪第 2 張](Vigiloom-UI-Concept-2-Revision-2.png) 延續白色頁首、藍色操作、淺色卡片與清楚的資訊層級；沿用既有 Vigiloom 導覽及設定入口。此頁處理管理員的背景工作，不重畫設備或應用服務頁面。

- 設定與帳號 → 背景工作：先看背景服務是否連線、等待／執行／失敗數，再看近期結果及必要的失敗說明。沒有資料時顯示空狀態；資料庫無法取得時顯示錯誤，不把未知數值顯示為零。
- 工作檢查間隔為受限制的選單，儲存後有明確回饋；文字說明它不影響設備 Ping。伺服器端再檢查 Administrator、選項及操作稽核。
- 進階管理連到同站 Hangfire Dashboard，返回連結回到 Vigiloom 背景工作頁。匿名與 Read only 不顯示設定入口，也不能直接取得後端畫面或發動操作。
- 以隔離 SQL 測試資料與測試帳號，在 in-app browser 走查桌面及 390 px 窄螢幕、儲存設定、返回與 Dashboard 即時統計。走查時修正表單元件樣式作用範圍、字體與 Dashboard 統計 POST；沒有使用真實客戶資料。
