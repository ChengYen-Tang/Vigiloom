# REQ-09 Ping 設定與最新狀態

沿用 [已選第二輪第 2 張](Vigiloom-UI-Concept-2-Revision-2.png) 的白色卡片、淺色背景、藍色操作與表格。透過 Product Design 的既有產品延伸流程，使用既有設定頁／設備頁結構，不另做全站原型。

- Administrator 從「設定與帳號 → Ping 監測」管理間隔、逾時、門檻與每 Worker 併發，欄位標明範圍。衝突要求重新整理；輸入錯誤保留表單，後端驗證同樣執行。
- 設備清單只顯示主要目標 Ping，詳情逐一呈現主要與額外目標，包含解析地址、狀態、最近結果、成功延遲、量測時間及位置。主機 Agent／應用服務不混入 Ping。
- 顯示目前有效規則；未達門檻與最近一次結果分開，未知、過期、權限不足、DNS 與監測器錯誤用明確文字。失敗沒有延遲，以「—」表示，不能補 0。
- Read only 可讀監測資料，不顯示設定入口或允許設定請求；匿名 API 不回傳設備或位址。畫面表格在窄螢幕可水平捲動，主要操作與標籤仍可用。
- 歷史查詢／趨勢及彙總由 REQ-10 交付；本需求只呈現真正最新結果及狀態依據，不放假圖表。
